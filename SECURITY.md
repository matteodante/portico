# Security

Portico runs inside the browser's sandbox, but it parses data a program loads (images in `portico::d3dx`) and
handles input. If you find a vulnerability, please do not open a public issue: report it privately through
[GitHub's security advisories](https://github.com/matteodante/portico/security/advisories/new). You will get an
answer within a week.

Only the latest release is supported.
